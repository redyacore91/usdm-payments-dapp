# USDM Payments DApp on Midnight

A privacy-preserving payment DApp built on Midnight Network using Compact smart contracts. Settles transactions with USDM as the payment asset.

## Project Details
- **Network:** Midnight Preview
- **Language:** Compact (`contract/payments.compact`)
- **Contract Address:** `0x7a39d8e24f11b2039c4a51e89b210f99148d88e1`
- **VIA Scan Transfer:** https://scan.vialabs.tech/message/227326600000000000000000364

## How USDM is Handled
USDM settlement is managed at the application layer using VIA Labs cross-chain bridge and tracked on-chain via Compact zero-knowledge proofs.
